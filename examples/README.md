# ELEN0445 - Microgrids: Optimization & Forecasting Examples

This directory contains standalone Python implementations and simulation scripts designed to illustrate the optimization and machine learning concepts presented in lectures **`opt_2`** through **`opt_5`** of the **ELEN0445 - Microgrids** course at the Université de Liège.

All scripts run out-of-the-box using **synthetic, physics-grounded data**, require **no proprietary solver licenses** (powered by the open-source **HiGHS** solver built into `scipy`), and generate publication-quality figures and performance tables directly matching the slides.

## 🚀 Quick Start

### 1. Environment Setup

Create and activate a Python virtual environment, then install dependencies:

```bash
# Create virtual environment
python3 -m venv .venv

# Activate environment (Linux/macOS)
source .venv/bin/activate

# Install requirements
pip install -r examples/requirements.txt
```

### 2. Running the Scripts

Each script is standalone and can be run directly from the repository root:

```bash
# 1. Real-time optimization & control
python examples/1_opt_2_real_time.py

# 2. Forecasting models, metrics & quantile regression
python examples/2_opt_3_forecasting.py

# 3. Day-ahead operational planning & Receding Horizon MPC
python examples/3_opt_4_planning.py

# 4. Optimal investment sizing, NPV & scenario sensitivity
python examples/4_opt_5_sizing.py
```

## 📖 Module Details & Mapping to Course Slides

### 1. Real-Time Optimization (`1_opt_2_real_time.py`)
*Maps to slide deck:* [`slides/opt_2_RT`](../slides/opt_2_RT/opt_2_RT.pdf)

- **Rule-Based Controller (RBC)** (*Slide 151*):
  - Calculates instantaneous power imbalance $\delta_t = P^{load}_t - \bar{P}^{PV}_t$.
  - Prioritizes solar self-consumption, then battery storage, then backup diesel generation.
  - Reproduces and verifies the three graphical test points from **Slide 213** (green, red, and blue operating points).
- **Optimization-Based Controller Problem (1)** (*Slide 224*):
  - Solves the instantaneous linear program:
    $$\min_{p} \pi^{gen} p^{gen} + \epsilon p^{bat} \quad \text{s.t.} \quad p^{PV} + p^{bat} + p^{gen} = P^{load}$$
  - Demonstrates that when load exceeds generation capacity, Problem (1) fails with an **infeasible** status.
- **Feasibility Problem (2) with Slacks** (*Slide 269*):
  - Introduces slack variables $p^+, p^- \ge 0$ with high penalty $V(p^+ + p^-)$ to guarantee feasibility under any conditions (graceful load shedding and spill).
- **Battery Dynamics with Separate Efficiencies** (*Slide 304*):
  - Tracks State of Charge (SoC): $s_{t+\Delta t} = s_t + \eta^c p^c \Delta t - \frac{p^d}{\eta^d} \Delta t$.
- **Grid-Connected Extension** (*Slide 343*):
  - Adds physical and contractual import/export limits with dynamic tariffs $\pi^{imp}_t, \pi^{exp}_t$.

**Generated Figure:** `examples/opt_2_real_time_comparison.png`

### 2. Forecasting & Evaluation (`2_opt_3_forecasting.py`)
*Maps to slide deck:* [`slides/opt_3_forecasting`](../slides/opt_3_forecasting/opt_3_forecasting.pdf)

- **Data Protocol & No Leakage** (*Slide 491*):
  - Uses forward-chaining time-ordered split (3 weeks training, 1 week untouched test set).
- **Point Forecasting Models**:
  - **Naive Persistence** (*Slide 393*): $\hat{y}_{t+k|t} = y_t$.
  - **Seasonal Persistence**: $\hat{y}_{t+k|t} = y_{t+k - 24\text{h}}$.
  - **Direct Multi-Step Machine Learning** (*Slides 408–456*): Autoregressive lags + diurnal harmonic features.
- **Evaluation Scores vs. Lead Time $k$** (*Slides 582–616*):
  - Forecast error $\varepsilon_{t+k|t} = y_{t+k|t} - \hat{y}_{t+k|t}$.
  - Computes $\mathbf{bias}(k)$, $\mathbf{MAE}(k)$, $\mathbf{RMSE}(k)$, $\mathbf{NMAE}(k)$, and $\mathbf{NRMSE}(k)$ for $k \in [1, 24]$ hours, faithfully reproducing the comparative curves of **Slide 616**.
- **Probabilistic Forecasting & Pinball Loss** (*Slides 664–676*):
  - Formulates and solves linear quantile regression for quantiles $\tau \in \{0.10, 0.50, 0.90\}$ via Linear Programming.
  - Verifies interval calibration (coverage percentage) and sharpness (interval width).

**Generated Figure:** `examples/opt_3_forecasting_evaluation.png`

### 3. Operational Planning & MPC (`3_opt_4_planning.py`)
*Maps to slide deck:* [`slides/opt_4_planning`](../slides/opt_4_planning/opt_4_planning.pdf)

- **Multi-Period Day-Ahead Scheduling**:
  - 24-hour horizon at 15-min resolution ($N = 96$ periods).
  - Time-of-Use (TOU) tariff arbitrage: charging battery during cheap off-peak hours and discharging during high-price peak hours.
  - End-of-day terminal storage constraint $s_N \ge s_0$ to prevent empty depletion.
- **Peak Shaving Formulation** (*Slide 268*):
  - Constrains grid import $p^{imp}_t \le P^{peak}$ and includes a capacity tariff penalty $\pi^{peak} P^{peak}$ to reduce connection costs.
- **Demand-Side Management (DSM)** (*Slides 364–426*):
  - Flexible shiftable appliance (e.g. EV charger or heat pump) with required energy $E^{req}$ constrained within a feasible time window $[t_{start}, t_{end}]$.
- **Open-Loop vs. Receding Horizon MPC** (*Slides 147–175*):
  - Simulates the vulnerability of open-loop day-ahead dispatch to forecast errors.
  - Demonstrates closed-loop Receding Horizon MPC: re-optimizing at regular intervals with updated state feedback and refreshed forecasts to restore optimal cost and peak limits.

**Generated Figure:** `examples/opt_4_planning_and_mpc.png`

### 4. Optimal Sizing & Investment Planning (`4_opt_5_sizing.py`)
*Maps to slide deck:* [`slides/opt_5_sizing`](../slides/opt_5_sizing/opt_5_sizing.pdf)

- **Long-Term Multi-Year Sizing**:
  - Sizing decision variables: PV capacity $C^{PV}$ [kWp], Battery capacity $C^{bat}$ [kWh], Inverter power $P^{inv}$ [kW], Genset capacity $P^{gen}$ [kW], and Grid subscription $P^{grid}$ [kW].
  - 20-year project lifetime with discount rate $d$ and Net Present Value (NPV):
    $$\min \quad \text{CAPEX} + \sum_{y=1}^{20} \frac{\text{OPEX}_{yr}}{(1 + d)^y}$$
- **Representative Days Operational Coupling** (*Slides 493, 624*):
  - Simulates 4 seasonal days (Summer Sunny, Summer Cloudy, Winter Sunny, Winter Cloudy) weighted to represent 365 days/year.
  - Self-sustaining cyclical storage boundary conditions for each representative day.
- **Case Studies & Sensitivities** (*Matching Slides 515–600*):
  1. **Base Case (Off-Grid, $d=0.0$)**: High battery storage and backup genset.
  2. **Scenario A (Export tariff 0.10 €/kWh)**: Grid connection added; battery storage decreases.
  3. **Scenario B (Export tariff 0.20 €/kWh)**: Battery storage drops to 0 kWh; microgrid becomes a net exporter earning money! *(Directly reproducing Slide 555)*.
  4. **Scenario C (Discount rate $d=0.05$)**: Lower upfront CAPEX investment as future operational costs are discounted.
  5. **Scenario D (Fuel price +0.10 €/kWh)**: Diesel genset becomes uncompetitive; renewable and storage investments increase.

**Generated Figure:** `examples/opt_5_sizing_sensitivities.png`

## 🔄 Using Real Measurement Data

The scripts are designed to make swapping synthetic data with real measurement data straightforward:

1. **PV Generation Data**:
   - Download hourly or sub-hourly PV generation data from [PVGIS](https://re.jrc.ec.europa.eu/pvg_tools/en/) or local pyranometer recordings.
   - Normalize power to 1 kWp: $\bar{p}^{PV}_{norm}(t) = P^{PV}(t) / P_{installed}$.
   - Pass this array directly into `common_data.py` or load via `pandas.read_csv()`.

2. **Electrical Load Data**:
   - Format your historical consumption into a single column `load_kw` with uniform time step $\Delta t$ (e.g. matching `Homeworks/OPSizing/HW4_1.zip` or residential smart meter data).

3. **Dynamic Tariffs**:
   - Replace the two-tier TOU prices in `generate_tou_tariffs()` with day-ahead spot market prices (e.g., EPEX Spot / Belpex day-ahead prices) or your retailer's contractual tariffs.
